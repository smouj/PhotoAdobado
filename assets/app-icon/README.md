# PhotoAdobado app icon

Arte original para PhotoAdobado: marco de foto, sol y montañas sobre el tile del kit.

Licencia: MIT OR Apache-2.0, igual que el código del proyecto.

Los archivos derivados (photocraft-1024.png, photocraft.ico, photocraft.svg,
photocraft-small.svg y hicolor/) se generan a partir del mismo dibujo. El nombre
de archivo photocraft se conserva porque build.rs y app_icon.rs lo referencian.
