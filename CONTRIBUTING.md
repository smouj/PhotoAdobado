# Contribuir — PhotoAdobado

PhotoAdobado es un derivado de PhotoCraft. Antes de enviar cambios:

1. Lee docs/contributing.md del upstream.
2. Mantén las licencias MIT/Apache y los avisos de procedencia.
3. No introduzcas marcas, logos o assets de ArtCraft.
4. Prueba abrir, editar y exportar en local.
5. Documenta el cambio en CHANGELOG.md.

Para cambios de marca o producto, coordina con Adobado Kit:
https://github.com/smouj/Adobado_Kit
