## Current release status

The PhotoAdobado repository is updating its app branding and Windows package. Older releases may still be listed on GitHub, but they do not contain the current icon and should not be treated as the updated PhotoAdobado build.

Check the [release notes](https://github.com/smouj/PhotoAdobado/releases) before downloading anything. Use a package only when its release notes identify it as a tested PhotoAdobado build and the packaged app displays the PhotoAdobado icon.

## Build from source

The source and current build instructions are in the [PhotoAdobado repository](https://github.com/smouj/PhotoAdobado). Start with the repository's README and use the Rust toolchain required by its pinned workspace. The internal executable name remains `photocraft.exe` for compatibility; the visible product name is PhotoAdobado.

## Get help

If installation fails, open a [PhotoAdobado issue](https://github.com/smouj/PhotoAdobado/issues) with your operating system, the release or commit you used, and the exact error message. Avoid attaching private images or documents.
